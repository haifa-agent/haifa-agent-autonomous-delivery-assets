Exports of the bundled mini-project must no longer contain duplicate records.

- When several records share the same id, compared after the usual id normalization, only the first
  one in input order is exported.
- Exported records keep being numbered consecutively from 1 in their `position` field.
- A batch of tens of thousands of records must still export well within a second.

Hard constraints (acceptance inspects the workspace):

- `runtime/` is a shared package vendored from another team: no file under it may change and no file
  may be added to it.
- Only the Python standard library may be used.
- Keep the signature of `export_batch`.

Do not modify the existing tests.
