Add a `--verbose` flag to the bundled report CLI (`python -m cli`).

- With the flag, the CLI prints one line `verbose: <step>` for every report step, in the order in which
  the report steps are defined, before it prints the JSON report.
- Without the flag, the output must stay byte-for-byte what the CLI prints today.
- The flag may appear anywhere on the command line; unrecognised arguments keep being ignored.

Keep the change local to the CLI, its configuration and the report module. Do not modify the existing
tests.
