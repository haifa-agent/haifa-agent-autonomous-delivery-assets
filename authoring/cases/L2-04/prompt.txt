The exporter of the bundled mini-project supports JSON only. Add a `csv` export format next to it:

- the first line is a header made of the first row's keys, followed by one line per row in input
  order, with `\n` line endings;
- values are written as valid CSV: a value containing a comma, a double quote or a line break is
  quoted as usual; an empty row list exports as an empty string;
- `exporter_for("csv")` returns the new exporter, and the CLI (`python -m cli`) accepts
  `--format <name>`, defaulting to `json`;
- an unknown format still makes `exporter_for` raise `ValueError`; the CLI reports it on stderr and
  exits with code 2.

The existing JSON output must stay byte-for-byte identical. Do not modify the existing tests.
