Add an optional integer parameter `max_retries` to the `send_notification` tool of the bundled opsdesk
project: default 3, allowed range 0..5 inclusive.

- Values outside the range and values that are not integers are rejected with `ValueError` before the
  handler runs.
- A handler invoked through `invoke_tool` always receives `max_retries` as an `int`: the caller's
  value, or the default when the caller omits it.
- `describe_tools()` advertises the parameter with type `integer` and with its `default`, `minimum`
  and `maximum`.

Existing parameters and behaviour must not change. Respect the layering rules described in
`AGENTS.md`. Do not modify the existing tests.
